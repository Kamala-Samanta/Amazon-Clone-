## Introduction

This project is a simplified clone of the Amazon website. It showcases fundamental web development skills using HTML and CSS. The goal of this project is to replicate the look and feel of the Amazon website while focusing on the front-end design.

## Features

- Home page with product listings.
- Product detail pages.
- Static content representation.

## Technologies Used

- **HTML**: Structure of the web pages.
- **CSS**: Styling and layout of the web pages.

## Setup and Installation

To run this project locally, follow these steps:

1. **Clone the repository:**

   ```bash
   git clone https://github.com/Kamala-Samanta/Amazon-Clone-.git

   
2. Navigate to the project directory:
    ```bash
    cd Amazon-Clone-


3. Open index.html in your browser:

   You can simply open the index.html file in a web browser to view the project.

## Usage
  After setting up the project, you can navigate through the different pages to see the replicated design of Amazon. This project is static and does not include back-end functionality.
